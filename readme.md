# Download Count

The Download Count module tracks downloads of private files attached to nodes via file fields.

## Installation

- Install this module using the official [Backdrop CMS instructions](https://backdropcms.org/user-guide/modules).

## Issues

Bugs and feature requests should be reported in the [Issue Queue](https://github.com/backdrop-contrib/download_count/issues).
